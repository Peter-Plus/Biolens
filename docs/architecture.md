# 架构与行为约定

## 分层

Electron main 管理目录选择、下载保存、Python子进程及短期本地访问令牌。渲染进程启用contextIsolation与sandbox，不暴露Node或任意文件读取。

React使用HTTP调用FastAPI，通过SSE订阅工具进度。后端监听127.0.0.1，客户端启动时使用随机端口与随机访问令牌。Web版本将来复用UI与API，需替换本地目录选择并增加远程认证。

LangGraph循环：模型决策 → 工具调用 → 返回结构化结果 → 模型继续或回复。最多12轮。SQLite持久化项目、聊天、运行和工具事件。应用重启将未完成任务标为interrupted，不自动恢复副作用。

## 权限与模式

本地读取关闭：不向模型暴露本地工具；工具自身也检查开关与解析后的路径。拒绝路径越界、符号链接越界和已知密钥文件。

外部检索关闭：不提供PubMed工具。开启时，先判断用户当前消息是否明确请求外部检索；明显否定优先，明确请求走规则，其余由不带工具的模型分类。含糊复杂的表达仍可能误判，失败案例和回归用例保留。

聊天模式：回答或运行用户要求的工具，不提供create_report。报告模式：需求不明确先追问；明确后执行并调用create_report，输出格式严格使用用户的枚举选项。

工具返回的资料是数据而非指令。模型系统提示明确该边界，但不把提示词当成唯一安全机制。

## 计算约定

表达矩阵首列是唯一基因ID，列名是唯一的样本ID。样本表至少含sample_id和显式选定的分组列。样本集合必须完全一致；不静默插补、去重或删除。

PCA使用输入表达值，去除恒定基因、按基因中心化，不做方差缩放。可显式指定log1p，默认none。热图选取最多20个高方差基因做行z-score；它不是差异表达筛选。

## 报告与证据

源结构记录正文、图形参数、文献摘要来源与数据哈希。所有模型正文在HTML中转义，不执行模型HTML/JS。Plotly生成受控交互图；Playwright渲染同一规格为静态图片和PDF。

引用校验只证明PMID来自本轮检索，不能证明每个论断被文献充分支持。仍需人工复核引用对应关系、研究设计和证据强度。检索结果年份统计只代表本次获得的集合。

## 扩展位置

- 新数据分析：新增确定性工具、输入模型和数值测试，再注册工具定义。
- 新信息源：实现检索适配器，保留来源定位信息，沿用权限检查。
- 新模型：正式客户端由云端目录管理；开发模式兼容接口可改设置；特殊协议应新增模型适配层，不修改分析模块。
- 新格式：在统一报告结构之上增加导出器。

## 当前局限

无任意Python执行、无OCR、无自动差异表达、无断点自动恢复。长会话只使用近期16条消息，旧资料需要重新读取。模型生成正文的事实正确性不能由格式/PMID校验替代。


## 云端与本地边界（0.2.0）

正式 Electron 客户端启动本地执行器，并连接固定 HTTPS 云端。React 仍只访问本地执行器；云端会话令牌仅保存在执行器内存，退出或重启后需要重新登录。

`biolens_cloud` 独立负责账号、归属校验、项目/聊天元数据、模型目录、推理代理和文献检索。密码采用带随机盐的 scrypt，数据库只保存会话令牌哈希。每账号最多一个进行中的推理请求，全局最多五个；服务端不执行用户代码。

本地 `account` 负责登录边界，`cloud_client` 管理请求会话，`cloud_sync` 通过事务 outbox 和消息 UUID 幂等同步。账号 ID 决定本地 SQLite 工作区；切换账号不会混入旧本地数据。任务运行期间不能切换账号。

本地目录绑定不上传；报告和数据文件不自动上传或跨设备同步。工具实际读取的资料片段、分析摘要会作为推理上下文发往服务器及模型商；用户自己输入的路径或资料文字仍属于聊天内容，会随聊天同步。工具执行记录保存在本地。

文献工具优先请求 NCBI；不可用时使用 Europe PMC 的 PubMed 收录记录，并在结果中标明备用来源。检索在服务端串行执行并留出间隔，减少集中请求触发上游限制。


## 双端复用与网页执行

React 使用 `src/api.ts` 中的平台适配判断桌面 IPC 或同源 `/web-api`。网页版新增独立 `ProjectFiles` 组件，既有聊天、模型选择、报告和成果组件保持复用。

`backend/biolens/web.py` 提供浏览器会话、上传目录、删除文件和执行队列；复用同一 Runner、分析模块和报告导出器。`BIOLENS_WEB=1` 时挂载网页账号路由，以请求级 ContextVar 绑定用户，不使用桌面单用户全局会话。HTTPOnly/Secure/SameSite Cookie 保护会话，写入请求校验 Origin。服务器路径绑定在网页模式下明确拒绝。

网页版任务持久化于每账号 SQLite，asyncio 单槽队列限制计算资源；页面生命周期与后台任务解耦。当前服务为单进程，后续若多副本部署，应把任务队列和任务锁迁移到共享存储，不可直接增加 Uvicorn workers。
